# Fully open source; any revenue comes from convenience

OpenAlg's code is fully open source. If it ever earns money (in the style of Kuta Software's paid licences), it will be by selling convenience — the hosted app, Library sync, school licences — not by keeping the generator closed. We chose this over a proprietary app or an open core because the name promises openness and because community-written Topics are only realistic if the engine is open. The licence is AGPL-3.0, so nobody can run a closed hosted fork. Contributors sign off their commits (DCO) rather than signing a CLA. We accept that this rules out relicensing the code later.
